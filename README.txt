CNC COPILOT FULL v1.1.1
========================

Назначение
----------
Автономный CNC-напарник для токарного техпроцесса: материал -> заготовка -> операции -> стратегия -> результат.
FULL v1.1.1 сохраняет офлайн-ядро v1.0.1 и добавляет «Умный шкаф», строгий AI-сканер пластин,
реальные фото инструмента, ISO-цветовую навигацию и активные требования чертежа.

Главные изменения FULL v1.1.1
-----------------------------
1. Liquid Glass / Apple-style UI
   - единый тёмный glass-интерфейс;
   - мягкие blur/highlight/tint эффекты и плавные переходы;
   - цвет выбранной ISO-группы проходит через материал, операции, инструмент и результат;
   - ISO P — синий, M — жёлтый, K — красный, N — зелёный, S — оранжевый, H — розовый;
   - полимеры PA6/POM получают отдельный холодный cyan/violet акцент.

2. Материал
   - существующая логика расчёта сохранена;
   - карточки материала теперь визуально кодируются по ISO;
   - выбранный материал задаёт tint последующим шагам.

3. Конструктор операций
   - текущая логика маршрута и повторяющихся операций сохранена;
   - на карточке операции есть быстрые «− / +» рядом со счётчиком;
   - операции показывают связанный инструмент из «Моего шкафа», когда он есть;
   - добавлен мультивыбор нескольких инструментов/пластин для одного техпроцесса;
   - выбранные требования чертежа видны в маршруте и предзапусковой проверке.

4. Стратегия
   - «Безопасный / Рабочий / Производительный» по логике не менялись.

5. Результат
   - вместо абстрактного «рекомендованного инструмента» приоритетно показывается реальный инструмент из шкафа;
   - карточка показывает пластину, державку, ячейку, количество и назначение;
   - реальное фото лицевой стороны пластинки имеет приоритет над условной SVG-формой;
   - фото торца хранится вторым кадром;
   - если подходящего инструмента в шкафу нет, Copilot честно помечает вариант как «КАТАЛОГ / НЕ ПОДТВЕРЖДЕНО В ШКАФУ»;
   - существующий «Первый пробный проход», пересчёт по симптомам и «Всё отлично» сохранены;
   - локальный проект, PDF/печать, PNG и «Новый проект» сохранены.

6. Умный шкаф
   - ручное добавление: державка, пластина, grade, стружколом, R, ISO, ячейка, количество, назначение;
   - реальные фото: лицо и торец пластинки;
   - поиск и ISO-фильтр;
   - быстрый учёт количества;
   - понятное назначение: торцовка, наружное точение, расточка, канавка, отрезка, резьба и т. д.;
   - старые пользовательские карточки v1.0.1 автоматически мигрируют в новую локальную базу.

7. Сканер пластин — STRICT SCAN MODE
   AI в этой сборке имеет ровно одну функцию: распознать инструмент по фото и предложить карточку.
   Он не выбирает режимы резания, не ведёт чат и не принимает технологические решения.

   Можно:
   - сделать фото камерой;
   - выбрать готовое фото из галереи;
   - передать до 4 фото одной позиции: коробка/этикетка, лицо, торец, дополнительный кадр;
   - проверить и отредактировать распознанные поля перед сохранением.

   Сканер извлекает, когда это видно на фото:
   - производителя;
   - маркировку пластины;
   - grade;
   - chipbreaker/стружколом;
   - радиус вершины;
   - ISO P/M/K/N/S/H;
   - приоритеты по точкам на упаковке: залитая = primary, контурная = secondary;
   - назначение/операции, только когда они следуют из видимой маркировки/геометрии.

   Защита от дублей:
   - перед созданием карточки проверяется ключ «маркировка + grade + chipbreaker + R»;
   - если позиция уже есть, Copilot показывает ячейку и количество;
   - действие по умолчанию — увеличить количество существующей позиции;
   - «Это другая» позволяет сознательно создать отдельную карточку.

8. Допуски, посадки, резьбы
   - справочник сохранён;
   - добавлен слой «Требования чертежа»;
   - требование можно привязать ко всей детали или к конкретной операции;
   - точные поля (например IT5–IT8) помечаются как критичные и влияют на финишную стратегию/контроль;
   - отображается целевой размер в середине рассчитанного поля допуска, когда применимо;
   - метрическая резьба имеет расширенный список M1…M100 и редактируемый шаг;
   - для нестандартного требования есть ручное поле.

Что работает полностью офлайн
-----------------------------
- профиль станка и setup RPM;
- материалы, маршрут, стратегии и расчёт S/Vc/f/ap;
- оценка мощности и теоретической Ra;
- локальный шкаф и фотографии, уже сохранённые на устройстве;
- проекты/проверенные режимы;
- JSON backup/import;
- справочник и активные требования чертежа;
- PDF через системную печать и PNG-карточка;
- PWA/service worker после первого кеширования.

Важно: AI-распознавание фотографий не является офлайн-функцией. Оно требует серверного API-эндпоинта и сети.
Если AI endpoint недоступен, сканер не ломает приложение: фотографии остаются в форме, поля можно подтвердить вручную;
на поддерживаемом браузере дополнительно может использоваться экспериментальный локальный TextDetector.

Запуск без AI — статический PWA
-------------------------------
1. Распаковать папку CNC-Copilot-FULL-v1.1.1.
2. Опубликовать index.html, app.js, data.js, styles.css, manifest.webmanifest, sw.js, icons и vendor как обычный static site.
3. Для GitHub Pages содержимое папки положить в корень Pages-репозитория.
4. После обновления удобно один раз открыть адрес с ?v=110.
5. На iPhone: Safari -> Поделиться -> На экран «Домой».
6. После первого полного открытия офлайн-ядро кешируется.

На чистом GitHub Pages AI-vision endpoint отсутствует — это ограничение статического хостинга, не PWA.
Все остальные функции продолжают работать.

Запуск полного AI-сканера
-------------------------
В комплекте есть server.mjs без npm-зависимостей. Нужен установленный Node.js 18+ и API key в переменной окружения.
API key НИКОГДА не вставляется в app.js/index.html и не хранится в браузере.

macOS / Linux:
  OPENAI_API_KEY="ваш_ключ" node server.mjs

Windows PowerShell:
  $env:OPENAI_API_KEY="ваш_ключ"
  node server.mjs

Затем открыть адрес, который напечатает сервер (по умолчанию http://localhost:8787).
Модель можно переопределить переменной OPENAI_SCAN_MODEL. По умолчанию используется gpt-5.6.

Для телефона нужен HTTPS-доступ к этому же серверу/домену. В production лучше разместить server.mjs или эквивалентный
same-origin backend за HTTPS, а фронтенд оставить тем же. Эндпоинт: POST /api/scan-insert.

Локальные данные и обновление
-----------------------------
- станок, проекты, шкаф и черновик хранятся в localStorage устройства;
- фото перед сохранением уменьшаются, чтобы не расходовать память без необходимости;
- v1.1.1 делает неразрушающую миграцию старого cncFullToolsV1 / cncFullDraftV1, если новая база ещё не создана;
- резервная копия JSON остаётся рекомендуемым способом переноса проектов и шкафа между устройствами.

Ограничения и безопасность
--------------------------
- CNC Copilot выдаёт стартовые технологические рекомендации, а не разрешение на запуск станка;
- перед реальным резанием проверяй зажим, патрон/кулачки, нули, коррекции, направление шпинделя, траекторию,
  лимиты оборотов, Dry Run/Single Block и документацию производителя;
- OEM M-коды задней бабки приложение не угадывает;
- встроенный модуль допусков — технологический помощник. Ответственные размеры и посадки сверяй по актуальной
  нормативной документации и технологической карте;
- AI-скан — распознавание маркировки, поэтому перед «Добавить в шкаф» пользователь всегда подтверждает карточку.
