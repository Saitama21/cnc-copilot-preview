CNC Copilot Preview v0.1.1

Что уже работает:
- iPhone-first интерфейс Liquid Glass
- выбор станка
- каталог материалов
- инструментальный шкаф
- заготовка Ø / длина
- операции: черновое, чистовое, торцевание, расточка, канавка, отрезка
- режимы: безопасный / рабочий / производительный
- расчёт S / F / Vc / ap
- вывод значений в формате SINUMERIK
- пробный проход
- простая экспертная корректировка по симптомам
- локальная история режимов
- PWA manifest + service worker

ВАЖНО:
Это Preview расчётного ядра. Значения режимов являются стартовыми рекомендациями,
не заменяют паспорт инструмента/пластины и контроль первого пуска.

Запуск:
1. Для быстрого просмотра на компьютере открой index.html.
2. Для PWA/service worker запускай через любой HTTP-сервер или Railway/GitHub Pages.
