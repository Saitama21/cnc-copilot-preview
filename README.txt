CNC COPILOT FULL v1.0.1
========================

Цель сборки
-----------
Не одиночный калькулятор, а автономный конструктор техпроцесса для токарной работы.

Что работает локально
---------------------
- профиль Tengyue CK52PT-Y / SINUMERIK 828D;
- материалы и диапазоны режимов;
- несколько операций в одном маршруте;
- черновая / чистовая / обе для поддерживаемых операций;
- автоматический подбор инструмента из локального шкафа;
- S, Vc, f, ap, оценка мощности и теоретической Ra;
- отдельная карточка режима для каждой операции;
- первый пробный проход и обратная связь по каждой операции;
- итеративный пересчёт: вибрация, свист, стружка, перегрев, поверхность, износ, нагрузка;
- подтверждение «Всё отлично» и сохранение проверенного режима;
- локальные проекты в localStorage;
- резервная копия JSON;
- PDF через системное окно печати Safari/Chrome;
- PNG-карточка техпроцесса;
- справочник IT5-IT14, H/h/JS/js, типовые посадки, метрические резьбы;
- подсказка ShopTurn по задней бабке;
- PWA/service worker: интерфейс и расчёт работают после кеширования без интернета.

Интерфейс
---------
Эталонный мобильный размер: iPhone 14 Pro (393 px по ширине CSS viewport).
Также адаптирован под другие смартфоны, планшеты и desktop.
Все анимации работают локально без внешних библиотек и CDN.

Установка на GitHub Pages
-------------------------
1. Распаковать архив.
2. Содержимое папки CNC-Copilot-FULL-v1.0.1 загрузить в корень репозитория GitHub Pages.
3. Дождаться успешного Pages deployment.
4. Первый запуск после обновления удобно открыть с ?v=101.
5. На iPhone: Safari -> Поделиться -> На экран «Домой».
6. После первого полного открытия PWA кеширует ядро для офлайн-работы.

Важно
-----
Расчёт является стартовой технологической рекомендацией, а не разрешением на запуск.
Перед реальным резанием оператор обязан проверить зажим, траекторию, нули, коррекции,
обороты патрона/кулачков, инструмент, направление шпинделя и документацию станка.
OEM M-коды задней бабки не угадываются: их можно вписать в профиль только после проверки паспорта.

Изменения FULL 1.0.1
---------------------
- исправлены safe-area iPhone и положение верхней glass-панели;
- нижний dock больше не должен перекрывать карточки и кнопки;
- hero стал компактнее на iPhone 14 Pro;
- активный шаг центрируется в горизонтальном stepper;
- выбранные операции подсвечиваются, на карточке показывается счётчик повторов;
- порядок повторяющихся операций остаётся виден в маршруте;
- RPM-кольцо теперь показывает долю текущих оборотов от реального лимита RPM;
- рядом с кольцом появился живой SINUMERIK-блок S/F/Vc/ap;
- цифровые значения плавно анимируются после расчёта и пересчёта режима.
