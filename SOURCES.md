# CNC Copilot FULL v1.0.1 — источники и границы ядра

## SINUMERIK / ShopTurn
Локальная подсказка по задней бабке основана на руководствах SINUMERIK 828D Turning / ShopTurn:
- в программных настройках ShopTurn предусмотрен параметр Tailstock / «Задняя бабка» Yes/No;
- при включённой задней бабке учитывается плоскость отвода XRR;
- безопасные точки отвода и смены инструмента остаются ответственностью оператора;
- OEM M-коды механического подвода/отвода определяются изготовителем станка и в приложение автоматически не выдумываются.

## Режимы резания
База FULL v1.0.1 использует локальные стартовые диапазоны по ISO-группам и материалам плюс часть ранее добавленных каталожных профилей инструмента. Это технологическая стартовая модель, а не замена каталога конкретного grade/chipbreaker.

## Мощность
Оценка строится через удельную силу резания kc и объёмную нагрузку. Она предназначена для предупреждения о заведомо тяжёлом режиме, а не для сертифицированного расчёта мощности привода.

## Шероховатость
Для обычного точения используется геометрическая оценка по подаче и радиусу вершины. Фактическая поверхность зависит от биения, жёсткости, вибрации, материала, состояния кромки, СОЖ и станка.

## Допуски
IT5–IT14 рассчитываются по стандартной единице допуска для диапазона 1–500 мм. H/h/JS/js реализованы непосредственно. В типовых посадках g/f/k/p фундаментальные отклонения используются как встроенный справочный помощник; ответственные посадки необходимо сверять с актуальной официальной таблицей ISO 286.

## Безопасность
Ни одна рекомендация приложения не отменяет Dry Run / Single Block, проверку коррекций, зажима, патрона, кулачков, инструмента и документации производителя.
