# CNC Copilot FULL v1.1.1 — источники, стандарты и границы ядра

## OpenAI Vision — только модуль сканера

В FULL v1.1.1 AI изолирован в `server.mjs` и используется исключительно для распознавания фотографий инструментальной оснастки.
Браузер отправляет до четырёх изображений на same-origin `POST /api/scan-insert`, backend передаёт их в OpenAI Responses API.
В API key во фронтенд не попадает.

Архитектура опирается на официальную документацию OpenAI Images and vision:
- Responses API принимает изображения как input;
- изображение можно передавать URL или Base64 data URL;
- в одном запросе можно передавать несколько изображений;
- для OCR/мелкого текста у поддерживаемых моделей полезен detail `original`.

В сборке по умолчанию выбран `gpt-5.6`; модель можно переопределить через `OPENAI_SCAN_MODEL`.
AI не является источником режимов резания: его результат всегда попадает в редактируемую карточку перед сохранением в шкаф.

## ISO 1832 — обозначение сменных пластин

Маркировка геометрии пластин трактуется как обозначение сменных пластин по логике ISO 1832.
Текущая опубликованная база ISO: ISO 1832:2017, *Indexable inserts for cutting tools — Designation*.
Copilot не пытается восстановить невидимые символы по памяти: если маркировка не читается, поле остаётся неопределённым до подтверждения пользователя.

## ISO 286 — линейные допуски и посадки

Технологический помощник требований чертежа ориентируется на:
- ISO 286-1:2010 — basis of tolerances, deviations and fits;
- ISO 286-2:2010 — standard tolerance classes and limit deviations for holes and shafts.

Встроенный расчёт IT5–IT14 для 1–500 мм использует стандартную единицу допуска и напрямую реализует H/h/JS/js.
Для нескольких типовых полей g/f/k/p в справочнике используются упрощённые вычислительные приближения фундаментального отклонения.
Это сделано для технологической подсказки, а не для замены официальной таблицы предельных отклонений.
Ответственные посадки обязательно сверяются по актуальной нормативной таблице/КД.

## ISO 965 / ISO metric thread

Библиотека метрических резьб и классов допуска построена вокруг ISO general purpose metric screw threads.
Актуальная Part 1 на момент сборки: ISO 965-1:2026 — principles and basic data.
В приложении есть распространённые классы (например 6H/6g) и расширенный coarse-перечень M1…M100;
пользователь может вручную менять шаг для fine/non-default резьбы.

Формула `D − P` для ориентировочного сверла под метчик и геометрические подсказки — именно стартовые ориентиры;
они не заменяют таблицу производителя метчика, требования к проценту профиля, материалу и конкретной технологии.

## SINUMERIK / ShopTurn

Локальная подсказка по задней бабке основана на принципах SINUMERIK 828D Turning / ShopTurn:
- наличие задней бабки задаётся конфигурацией станка;
- точки отвода/смены инструмента и OEM M-коды зависят от конкретного станка;
- приложение не выдумывает M-коды механики и оставляет их ручной настройкой профиля.

## Режимы резания

Режимы FULL v1.1.1 остаются локальной стартовой технологической моделью по материалам, ISO-группам и профилям инструмента.
Сканер не изменяет Vc/f/ap: он только пополняет персональный шкаф. Затем обычное детерминированное ядро Copilot выбирает совместимый
инструмент пользователя и рассчитывает стартовый режим с учётом стратегии, станка, операции и обратной связи пробного прохода.

## Мощность и шероховатость

Оценка мощности использует удельную силу резания `kc` и объёмную нагрузку для предупреждения о тяжёлом режиме.
Теоретическая шероховатость — геометрическая оценка по подаче и радиусу вершины. Фактический результат зависит от жёсткости,
биения, вибраций, СОЖ, состояния кромки, материала и станка.

## Безопасность

Ни одна рекомендация приложения не отменяет Dry Run / Single Block, проверку зажима, нулей, коррекций, кулачков,
инструмента, допустимых оборотов, траектории и документации производителя станка/оснастки.
